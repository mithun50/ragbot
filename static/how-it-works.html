How RagBot works

Back to chat

RagBot reads documents of any size, finds the few passages that matter, and answers only from them, with a citation for every claim.

System overview

The browser talks to one FastAPI server. Answers stream back as server sent events.

flowchart LR
    U["User: text or voice"] --> FE["Web app: chat, sources, analytics"]
    FE -->|upload| API["FastAPI"]
    FE -->|"ask (SSE stream)"| API
    API --> ING["Ingestion pipeline"]
    API --> QA["QA engine"]
    ING --> STORE[("Index store: chunks and inverted index")]
    QA --> STORE
    QA --> LLM["OpenRouter: GLM 5.3 Flash, fallbacks Particle 1 and Ling"]
    QA --> AN[("Analytics log")]

Ingestion: any document size

Pages are streamed one at a time and never held in memory as a list, so a 1000 page PDF behaves like a 10 page one.

flowchart TD
    A["Upload streamed to disk in 1 MB pieces"] --> B["Background thread, 2 at a time"]
    B --> C["Parse page by page: PDF, DOCX, TXT, MD, CSV, JSON, HTML"]
    C --> D["Chunk: about 180 words, 30 word overlap, never across pages"]
    D --> E["Add 200 chunks at a time to the store"]
    E --> C
    C --> F["Finalize: BM25 statistics, save to disk"]
    F --> G["Status ready: searchable"]
    G --> H["Summary, key facts, suggested questions"]

Question answering

Multi-query keyword retrieval with fusion and re-ranking, a broader second pass that admits what the document does not say, and validated citations.

flowchart TD
    Q["Question"] --> CA{"Answer cache hit?"}
    CA -->|yes| R1["Replay answer in about 1 ms, 0 tokens"]
    CA -->|no| QE["Query expansion: 2 extra queries from key terms"]
    QE --> S["BM25 search per query, k = 16"]
    S --> RRF["Reciprocal rank fusion"]
    RRF --> GATE{"Top relevance above 0.12?"}
    GATE -->|no| NF["Add document-wide passages instead of refusing"]
    GATE -->|yes| MMR["MMR: pick 7 distinct passages"]
    MMR --> NB["Neighbour expansion on top 2 passages"]
    NB --> P["Numbered context under a word budget"]
    P --> L["Stream from the model with a strict grounding prompt"]
    L --> V["Validate citations against retrieved passages"]
    V --> D["Done: answer, citations, metrics"]
